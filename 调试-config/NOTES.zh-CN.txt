【EXITBS:START 卡死 —— 备用配置说明】
=====================================

现象：OpenCore 退出一瞬间（日志最后一行 [EB|LOG:EXITBS:START]）卡住，
屏幕文字定格 —— 这是"内存映射类 quirk 与固件不匹配"，华硕机型高发。
下面是 4 份备用 config（基于"安装阶段"正式配置，只改了 Booter 内存相关项），
请按顺序逐个尝试，每次只换一个文件。

  备用1  关闭 SetupVirtualMap                        ← 先试这个（最常见）
  备用2  备用1 + 关闭 DevirtualiseMmio
  备用3  备用2 + 关闭 ProtectMemoryRegions / ProtectUefiServices
  备用4  关闭 SetupVirtualMap + 关闭 RebuildAppleMemoryMap + 关闭
         SyncRuntimePermissions + 打开 EnableWriteUnprotector（固件无 MAT 方案）

用法（前提：你用的是本包的 EFI，U 盘上 EFI 文件夹在可见分区里）：
  1. 打开 U 盘 → EFI\OC\ → 把现有 config.plist 先复制一份改名 config.plist.bak
  2. 把本文件夹里的"备用1"复制到 U 盘 EFI\OC\ 下，改名 config.plist（覆盖）
  3. 重启，重进 OpenCore 选 macOS Base System 再试
  4. 能过 → 继续安装，并把成功的是哪个编号告诉我（我会并入正式配置）
     仍卡 → 依次换 备用2、备用3、备用4
  5. 每次只替换 config.plist，不要动 Kexts / ACPI / Drivers 文件夹

注意：
- 判断"真卡死"：等 2~3 分钟无变化 + U 盘灯不闪 = 真卡死；若之后自己黑屏/重启，
  把新的表现告诉我（可能是另一个环节）。
- 如果你用的不是本包 EFI（例如 1401.exe 生成的盘）：这套文件不能直接混用，
  改法见对话说明（在它的 config.plist 里把 <key>SetupVirtualMap</key> 后面的
  <true/> 改成 <false/>，位置在 Booter > Quirks）。

【2026-10-10 13:55 重大更新 —— 备用9：CPU 整套栈 + DSDT 修复】
================================================================
本轮通过交叉分析（1401 引擎源码 policy.py/bootfix.py、OpCore-Simplify 上游、
ACPICA 源码 tbxfload.c/nsload.c、照片逐行放大）确认了两个根因，并已全部修复：

【根因 1：x86_validate_topology panic（14 threads but 20 registered from MADT）】
 = Alder Lake 混合核缺完整 CPU 栈。1401 对 12 代的做法（已照抄）：
   Cpuid1Data 仿冒(已有 55060A00…) + ProvideCurrentCpuInfo=true
   + CpuTopologyRebuild.kext (v2.0.2) + boot-arg ctrsmt=full
   + 3 条 "force HT enabled" 内核补丁（b00t0x patches_ht.plist，Sequoia 用 MinKernel=24.0.0 那条）

【根因 2：DSDT 加载失败 → 整个命名空间被删除 → 10 表加载失败】
 报错链：ACPI Error: [\_SB.PC00.XHCI.RHUB.HS01] Namespace lookup failure
        → (DSDT) table load failure → AcpiNsDeleteNamespaceByOwner 删除全部节点
        → 之后所有引用 \_SB.PC00 的表全部失败（PC00/LPCB/XHCI 全丢）
 原理：固件用 If (CondRefOf (PU2C/PU3C)) 条件式创建 USB 端口设备（HS01-14/SS01-10）。
       旧 ACPICA（Apple 20160930）不执行模块级条件代码，解析到后面的
       If (CondRefOf (...HS01)) { Scope (...HS01) ...} 时端口不存在 → DSDT 失败。
       （Windows/新 ACPICA 会执行条件、跳过不存在的分支，所以只有 macOS 中招。）
 修复：在字节层把 26 个"门卫 If"头（opcode+pkglen+条件）替换为等长 NoOp，使
       USB 端口声明变为无条件 → 生成 DSDT.aml，config 里由 ACPI→Add 整体替换 DSDT
       （OpenCore 官方语义：DSDT 标识的表 = 替换而非追加）。
       26 处 = 外层 PU2C/PU3C 2 处 + HS01-14 内层 14 处 + SS01-10 内层 10 处；
       改动共 259 字节（258 补丁 + 1 校验和），长度与其余结构不变，已用 iasl 反汇编复核。

【本版（备用9）其余对齐 1401 验证配置的改动】
 - Kernel.Quirks.DisableRtcChecksum = true
 - Booter.Quirks.AllowRelocationBlock = true（防 STOP 0x16）
 - Booter.Quirks.ProtectMemoryRegions = false
 - BAR 保持安装期设置（ResizeAppleGpuBars=0 / ResizeGpuBars=-1，与 1401 一致）
 - Kernel.Block 的 IONDRVSupport 保持 Enabled=false（安装期不排除，装完驱动再开）

【校验】ocvalidate 1.0.8：No issues found ✓

【下次启动观察点（至关重要）】

   HPET _CRS→XCRS (1 处)、HPET _STA→XSTA (1 处)、_OSI→XOSI (11 处)；
   门卫 26 处 NoOp 保留。总变化 272 字节；iasl 反汇编复核：XCRS×1 / XSTA×1 / XOSI×11、_OSI 残留 0。
